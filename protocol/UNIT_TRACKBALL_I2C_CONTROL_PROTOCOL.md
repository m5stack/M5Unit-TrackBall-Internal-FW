## 1. 基本信息

| 项目 | 说明 |
| :--- | :--- |

| 可配置 I²C 地址范围（7 位） | `0x08 ~ 0x77` |
| 通信速率 | 支持 `100 kHz` 和 `400 kHz` I²C 总线速率；总线时钟由主机产生 |
| 寄存器地址宽度 | `8 bit` |
| 寄存器数据宽度 | `8 bit`；多字节数据由连续寄存器组成 |

| 非法读取返回值 | `0xFF` |

### 1.1 总线模式与速率

设备作为 I²C **从机**工作，外部主机负责产生 SCL 时钟。当前固件的 I²C 从机接口使用中断方式处理地址匹配、接收/发送字节、STOP、NACK 和总线错误，并启用时钟拉伸。因此主机可以使用 `100 kHz` 或 `400 kHz` 访问同一套寄存器协议，寄存器地址、数据格式和事务时序不变。

`100 kHz` 和 `400 kHz` 均属于当前支持范围，但实际可用速率仍受主机、上拉电阻、总线电容、线长和电源电压影响。使用 `400 kHz` 时，应确保 SDA/SCL 上升时间和波形满足 I²C Fast-mode 电气要求。主机应在每次事务中正确发送 STOP，或按本协议使用 REPEATED START 完成组合读操作。

### 1.2 访问权限

| 权限 | 含义 |
| :--- | :--- |
| `R` | 只读 |
| `W` | 只写 |
| `R/W` | 可读可写 |
| `R/C` | 读取后自动清零 |
| `Reserved` | 保留，不应访问 |

### 1.3 读写事务

#### 寄存器读取

推荐使用组合事务：

```text
START -> SLA+W -> Register Address -> REPEATED START -> SLA+R -> Data... -> NACK -> STOP
```

也可以先发送寄存器地址并结束写事务，再发起独立的读事务。主机必须先写入 1 byte 寄存器地址；不支持未指定寄存器地址的直接读取。

从连续寄存器组内任意地址开始读取时，设备会按地址递增返回该地址至当前寄存器组末尾的数据。超过当前组可返回长度后，后续字节返回 `0xFF`。例如，从 `0x01` 开始最多可读取 `0x01 ~ 0x03` 共 3 byte。

#### 寄存器写入

单次写事务格式为：

```text
START -> SLA+W -> Register Address -> Data -> STOP
```

普通寄存器每次只支持写入 1 byte。以下寄存器组额外支持从组内任意地址开始连续读写。连续写入时，设备按地址递增逐个寄存器进行参数校验和处理；某个寄存器的数据无效时，仅忽略该寄存器，不影响同一事务中其他寄存器的处理。`0x30 ~ 0x35` 是一个跨寄存器的按键时间参数组，仍按完整参数组进行关系校验，详见 `4.6`：

| 地址组 | 名称 | 权限 | 说明 |
| :--- | :--- | :--- | :--- |
| `0x30 ~ 0x35` | Key Timing | R/W | 连续读写按键时间配置 |
| `0x40 ~ 0x41` | Sensor Reinitialize / Clear Data | W | 连续写入命令寄存器（只写，读取返回 `0xFF`） |
| `0x50 ~ 0x51` | Axis Configuration / I2C Error Count | R/W | 连续读写轴配置与错误计数 |

从组内任意地址开始连续读写时，设备按地址递增返回或更新该地址至寄存器组末尾的数据，写入不能超过组末尾。除 `0x30 ~ 0x35` 的完整参数组校验外，各寄存器的写入结果相互独立。

## 4. 寄存器详情

### 4.1 Trackball Motion

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0x00 ~ 0x03` | `4 byte` | `R` | 返回最近一次采集到的 X/Y 轴位移数据 |

#### 参数说明

| 地址/偏移 | 名称 | 取值/范围 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `0x00` | `DX_L` | `0x00 ~ 0xFF` | `0x00` | X 轴位移低字节 |
| `0x01` | `DX_H` | `0x00 ~ 0xFF` | `0x00` | X 轴位移高字节 |
| `0x02` | `DY_L` | `0x00 ~ 0xFF` | `0x00` | Y 轴位移低字节 |
| `0x03` | `DY_H` | `0x00 ~ 0xFF` | `0x00` | Y 轴位移高字节 |

#### 数据格式

`DX` 和 `DY` 均为小端 `int16_t`：

```c
int16_t dx = (int16_t)((uint16_t)data[0] |
                       ((uint16_t)data[1] << 8));
int16_t dy = (int16_t)((uint16_t)data[2] |
                       ((uint16_t)data[3] << 8));
```

传感器固定工作在 Active 和 12 位位移模式，固件将符号扩展后的结果保存为 `int16_t`。默认用户坐标为 X/Y 均不反向且不交换；固件会把用户配置自动映射到传感器内部方向配置。

#### 注意事项

1. 读取位移寄存器不会自动清除 `Data Ready`；读取 `0x10` 寄存器会清除当前就绪标志。
2. 固件只保存最近一次采集值，不提供位移数据队列；新的运动采样可能覆盖尚未处理的旧值。
3. 从 `0x00` 开始连续读取 4 byte 获取 `DX/DY`；`Data Ready` 需要从 `0x10` 单独读取。

### 4.2 Data Ready

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0x10` | `1 byte` | `R/C` | 表示是否已采集到新的位移数据，读取后清零 |

#### 参数说明

| 地址/偏移 | 取值/范围 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `0x10` | `0` | `0` | 没有待处理的新位移数据 |
| `0x10` | `1` | `0` | 有新位移数据；固件采集到有效运动数据时置 `1` |

正常握手流程为：读取 `0x10`，返回 `1` 时该次读取完成后自动清零；主机随后读取 `0x00 ~ 0x03` 处理 `DX/DY`。如果读取期间固件又采集到新位移，`Data Ready` 保持为 `1`，不会被旧读取清除。对 `0x10` 的写入请求被忽略。

从 `0x10` 开始连续读取 3 byte 时，返回顺序为 `Data Ready`、`Key State`、`Key Event`。只读取前 1 或 2 byte 时不会清除 `Key Event`。

### 4.3 LED PWM Duty

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0x20` | `1 byte` | `R/W` | 设置并读取板载蓝色 LED 的 PWM 占空比 |

#### 参数说明

| 地址/偏移 | 取值/范围 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `0x20` | `0 ~ 100` | `0` | PWM 占空比，单位 `%`；`0` 为关闭，`100` 为最大亮度 |
| `0x20` | `101 ~ 255` | 不适用 | 写入时自动限制为 `100`，后续读取返回 `100` |

PWM 频率约为 `1 kHz`，设置写入后立即生效，系统复位后恢复为 `0`。

### 4.4 Key State

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0x11` | `1 byte` | `R` | 返回板载按键的实时状态 |

#### 参数说明

| 地址/偏移 | 取值/范围 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `0x11` | `0` | 运行时 | 按键释放 |
| `0x11` | `1` | 运行时 | 按键按下 |

按键输入为低电平有效，固件已将电平转换为上述逻辑值。

### 4.5 Key Event

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0x12` | `1 byte` | `R/C` | 返回最近一次按键事件，读取完成后自动清零 |

#### 事件定义

| 值 | 事件 | 说明 |
| :--- | :--- | :--- |
| `0x00` | `None` | 当前没有待处理事件 |
| `0x01` | `Single Click` | 单击 |
| `0x02` | `Double Click` | 双击 |
| `0x03` | `Long Press` | 长按 |

#### 默认识别参数

| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| 消抖时间 | `20 ms` | 按键电平持续稳定后才确认变化 |
| 双击间隔 | `300 ms` | 第一次释放后等待第二次按下的最大时间 |
| 长按时间 | `1000 ms` | 持续按下达到该时间时产生一次长按事件 |

这三个参数可通过 `0x30 ~ 0x35` I²C 寄存器或固件软件接口 `user_key_configure()` 修改。只有实际读取到 `0x12` 的数据字节后才清除事件；仅写入寄存器地址，或从 `0x10` 开始只读取前 1/2 byte，都不会清除。

### 4.6 Key Timing

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0x30 ~ 0x35` | `6 byte` | `R/W` | 配置按键识别时间，单位为 `ms` |

| 地址 | 名称 | 格式 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `0x30 ~ 0x31` | `Debounce Time` | 小端 `uint16_t` | `20 ms` (`14 00`) | 消抖时间 |
| `0x32 ~ 0x33` | `Double Click Time` | 小端 `uint16_t` | `300 ms` (`2C 01`) | 第一次释放后等待第二次按下的最大时间 |
| `0x34 ~ 0x35` | `Long Press Time` | 小端 `uint16_t` | `1000 ms` (`E8 03`) | 持续按下达到该时间后产生长按事件 |

参数必须同时满足：`Debounce Time > 0`、`Double Click Time > Debounce Time`、`Long Press Time > Double Click Time`。不满足时，整次写入被忽略，原配置保持不变。

可从组内任意地址开始连续读写，但写入不能超过 `0x35`。建议从 `0x30` 开始连续写入 6 byte，使三个时间参数同时生效。配置仅在当前运行期有效，复位或重新上电后恢复默认值。

### 4.7 MCU UID

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0xE0 ~ 0xEB` | `12 byte` | `R` | 返回 MCU 出厂固化的 96 bit 唯一识别码 |

UID 在上电初始化时读取并缓存。从 `0xE0 ~ 0xEB` 任意地址开始读取时，固件从对应 UID 字节返回至 `0xEB`。例如，从 `0xE8` 开始最多连续读取 4 byte。

12 byte 按 STM32 UID 的三个 32 bit 寄存器顺序排列，每个 32 bit 值以小端字节序存放。UID 只读，写入请求会被忽略。

### 4.8 IAP Upgrade

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0xFD` | `1 byte` | `W` | 触发系统复位，供配套 IAP 升级流程接管 |

#### 参数说明

| 地址/偏移 | 取值/范围 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `0xFD` | `0x00` | 不适用 | 不执行操作 |
| `0xFD` | `0x01 ~ 0xFF` | 不适用 | 写事务完成后触发 MCU 系统复位 |

#### 注意事项

1. 该寄存器只负责触发复位，不承载固件数据。
2. 写入非零值后，当前 I²C 会话随系统复位而终止。
3. 如需进入 IAP，复位期间应将 SCL 和 SDA 同时保持为低电平。Bootloader 启动约 `30 ms` 后检测两条线；两者均为低电平时提供约 `500 ms` 的初始 IAP 等待窗口，否则跳转回应用程序。
4. Bootloader 使用固定 7 位 I²C 地址 `0x54`，其升级命令和数据帧不属于本文档定义范围。
5. 触发复位后，应用寄存器的非持久化状态会恢复默认值；I²C 地址继续使用 Flash 中保存的值。
6. 应使用与本产品匹配的升级工具完成 Bootloader 接管和固件传输。

### 4.10 I2C Address

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0xFF` | `1 byte` | `R/W` | 读取或修改当前应用固件的 7 位 I²C 地址 |

#### 参数说明

| 地址/偏移 | 取值/范围 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `0xFF` | `0x08 ~ 0x77` | `0x3F` | 有效 7 位 I²C 地址；写入后立即切换 |
| `0xFF` | `0x00 ~ 0x07`, `0x78 ~ 0xFF` | 不适用 | 无效地址，写入被忽略，当前地址保持不变 |

#### 注意事项

1. 新地址在当前写事务结束后生效，下一次事务必须使用新地址。
2. 有效地址会写入 Flash；系统复位或重新上电后继续使用上次保存的地址。Flash 中无有效记录时使用默认地址 `0x3F`。
3. 写入与当前地址相同的值不会触发重新初始化。
4. 修改地址前，主机应确认目标地址未被同一总线上的其他设备占用。

### 4.11 X Accumulated Motion

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0x06 ~ 0x09` | `4 byte` | `R` | 返回自上次清除后累计的 X 轴位移 |

数据格式为小端有符号 `int32_t`。读取不会自动清零；需要清零时向 `0x41` 写入 `0x01` 显式清除（见 `4.17`）。从 `0x06` 连续读取 8 byte 可依次取得 X、Y 累计值。读取期间产生的新位移会计入下一次读取的累计值。

### 4.12 Y Accumulated Motion

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0x0A ~ 0x0D` | `4 byte` | `R` | 返回自上次清除后累计的 Y 轴位移 |

数据格式为小端有符号 `int32_t`。读取不会自动清零；需要清零时向 `0x41` 写入 `0x01` 显式清除（见 `4.17`）。累计值采用饱和保护，不会发生 `int32_t` 回绕。

### 4.13 Sensor Init Status

| 值 | 状态 | 说明 |
| :--- | :--- | :--- |
| `0x00` | `Success` | MOT6010 初始化成功，可以正常采集 |
| `0x01` | `Failed` | MOT6010 初始化失败，停止采集 |
| `0x02` | `Initializing` | 正在初始化或已有重新初始化请求等待主循环处理 |
| `0x03` | `Reserved` | 保留 |

上电时最多尝试初始化 3 次，不进行周期重试。重新初始化命令执行一次后，本寄存器更新为成功或失败。

### 4.14 Sensor Reinitialize

| 写入值 | 行为 |
| :--- | :--- |
| `0x01` | 请求主循环重新初始化 MOT6010 |
| 其他值 | 忽略 |

命令由主循环异步执行，不在外部 I²C 回调中阻塞操作内部传感器总线。重新初始化开始时会清除最近一次 `DX/DY`、`Data Ready`、X/Y 累计值和旧轮询状态；无论初始化最终成功或失败，都不会继续对外保留初始化前的运动数据。

`0x40` 与 `0x41`（只写）组成连续写组：从 `0x40` 开始连续写入 2 byte 时，两个寄存器分别校验和处理，可同时请求重新初始化并执行 `0x41` 清除命令；某一个寄存器的数据无效时，仅忽略该寄存器。从 `0x41` 开始单独写入仍按 `4.17` 处理。两个寄存器均为只写，读取返回 `0xFF`。

### 4.15 Axis Configuration

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0x50` | `1 byte` | `R/W` | 用户层 X/Y 方向及交换配置 |

| 位 | 名称 | `0` | `1` |
| :--- | :--- | :--- | :--- |
| `bit0` | `X_INVERT` | X 不反向 | X 反向 |
| `bit1` | `Y_INVERT` | Y 不反向 | Y 反向 |
| `bit2` | `XY_SWAP` | 不交换 X/Y | 交换 X/Y |
| `bit3 ~ bit7` | `Reserved` | 必须为 `0` | 写入被忽略 |

默认值 `0x00` 表示用户层 X/Y 均不反向且不交换。固件自动完成用户坐标与传感器内部坐标的映射，并始终保留 12 位模式。配置在主循环中应用；写入非法保留位时忽略。配置失败但成功回滚时，当前有效值保持不变；配置状态无法恢复时，初始化状态变为失败、停止采集并清除运动数据，等待 `0x40` 重新初始化。配置值发生改变并成功生效后，固件会清除最近一次 `DX/DY`、`Data Ready` 以及 X/Y 累计值，避免切换前后的坐标数据混合。重复写入当前有效配置不会清除数据。

`0x50` 与 `0x51`（错误计数）组成连续读写组：从 `0x50` 开始读取 2 byte 依次返回轴配置与错误计数；从 `0x50` 开始连续写入 2 byte 时，两个寄存器分别校验和处理，可同时设置轴配置并清零错误计数。写入 `0x51` 的 `0x00` 才清零，其他值仅忽略 `0x51` 的本次写入，不影响 `0x50` 的处理。

### 4.16 Sensor I2C Error Count

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0x51` | `1 byte` | `R/W` | 内部访问 MOT6010 的 I²C 读写事务失败累计次数 |

| 操作 | 行为 |
| :--- | :--- |
| 读取 | 返回内部访问 MOT6010 的 I²C 读写事务失败累计次数，不自动清零 |
| 写入 `0x00` | 请求主循环清零错误计数 |
| 写入其他值 | 忽略 |

计数达到 `0xFF` 后保持，不回绕。该计数统计内部访问 MOT6010 的 I²C 读、写事务失败，包括初始化和运行期访问；不统计外部主机访问本设备的 I²C2 事务。传感器返回值不符合预期但 I²C 事务本身成功时，不作为通信错误计数。清零请求由主循环处理，避免与内部访问错误计数同时修改。`0x51` 与 `0x50`（轴配置）组成连续读写组，见 `4.15`。

### 4.17 Clear Data

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0x41` | `1 byte` | `W` | 显式清零累计位移或位移数据 |

#### 命令定义

| 写入值 | 操作 |
| :--- | :--- |
| `0x01` | 清零 X/Y 累计位移（`0x06 ~ 0x0D`） |
| `0x02` | 清零最近一次位移数据 `DX/DY` 与 `Data Ready`（`0x00 ~ 0x03`、`0x10`） |
| 其他值 | 忽略 |

#### 注意事项

1. 清除操作由主循环异步执行，不在外部 I²C 回调中阻塞操作内部传感器总线。
2. 写入 `0x01` 只清除累计位移，不影响最近一次 `DX/DY` 与 `Data Ready`；清除后新产生的位移正常累加。
3. 写入 `0x02` 同时清除最近一次 `DX/DY` 与 `Data Ready`，避免出现 `DX/DY` 已归零但 `Data Ready` 仍为 `1` 的状态不一致；不影响累计位移。
4. 累计位移为只读寄存器，读取不再自动清零，必须通过 `0x41` 显式清除。
5. 本寄存器为只写，读取返回 `0xFF`。
6. `0x41` 与 `0x40`（重新初始化）组成连续写组，见 `4.14`。

## 6. 使用示例

### 6.1 读取位移与就绪状态

主机先向寄存器地址 `0x10` 发起 1 byte 读取，确认返回 `01`。然后向 `0x00` 发起 4 byte 连续读取，假设返回：

```text
05 00 FD FF
```

解析结果：

| 字段 | 原始数据 | 解析值 |
| :--- | :--- | :--- |
| `DX` | `05 00` | `5` |
| `DY` | `FD FF` | `-3` |
| `Data Ready` | `01` | 有新数据（从 `0x10` 单独读取） |

`Data Ready` 在上述 `0x10` 读取完成后已自动清零，主机无需写入确认。

### 6.2 设置 LED 亮度

向 `0x20` 写入十进制 `50`（`0x32`），将 LED PWM 占空比设为约 `50%`：

```text
20 32
```

### 6.3 修改运行时 I²C 地址

设备当前地址为 `0x3F` 时，向 `0xFF` 写入 `0x40`：

```text
FF 40
```

该事务完成后，设备立即改用 7 位地址 `0x40`；复位后继续使用 Flash 中保存的 `0x40`。

## 7. 异常与边界行为

| 场景 | 设备行为 |
| :--- | :--- |
| 读取保留或未实现地址 | 返回 `0xFF` |
| 连续读取超过当前寄存器组末尾 | 超出部分返回 `0xFF` |
| 写入只读、保留或未实现地址 | 忽略写入，不改变设备状态 |
| 非寄存器组写事务长度不是 2 byte | 不执行寄存器写操作 |
| 寄存器组写入超过组末尾 | 忽略整次写入，保留原值 |
| 按键时间写入超过 `0x35` 或参数关系无效 | 忽略整次写入，保留原配置 |
| 写入非法 I²C 地址 | 忽略写入，继续使用当前地址 |
| I²C 写事务未正常结束 | 固件在约 `500 ms` 后尝试恢复 I²C 从机外设 |
